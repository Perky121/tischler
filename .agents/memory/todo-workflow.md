**Pravilo:** Svaki agent (Replit ili Cursor) čita `TODO.md` u korijenu projekta PRIJE rada.

Označi stavke s [x] kad su gotove. Ne briši gotove stavke — povijest je važna.

Faze projekta:
- **Faza 0** — Browser testing tool (Replit) — trenutno u tijeku
- **Faza 1** — Electron desktop app (Cursor SSH → Replit backend)
- **Faza 2** — Glasovni unos (push-to-talk, OpenAI Whisper)
- **Faza 3** — Live mod (proaktivni screen monitoring)

**Zašto:** Korisnik ima jasan plan i želi konzistentnost između sesija i alata.
